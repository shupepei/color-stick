# カラーステッキ (Color Stick)

横から見ると数字の「1」！たった「1」つのボタンでセカイの色を吸い取り、魔法のトーチのように光り輝く体験型ガジェットです。
Protopedia主催のハッカソンテーマ「1」に合わせて制作された新感覚カラーセンサートイです。

## 特徴
- **シルエットが「1」**: 専用エンクロージャーは横から見ると数字の「1」の形をしています。
- **「1」ボタン操作**: M5Stack ATOM S3の画面押し込みボタン1つだけで全操作が完結します。
- **「1」滴の色を混ぜる**: 現実の色をスポイトで吸い取るようにスキャンし、直感的に混色できます。
- **トーチのような光**: ステッキの先端（1のあたま）が、スキャンした色で鮮やかに光ります。

---

## はじめに（ホワイトバランス設定）
起動すると、環境光のズレを補正するためのキャリブレーション（ホワイトバランス設定）が始まります。
画面に「しろいろを おぼえさせるよ」と表示されるので、白色LEDを「白い物体（紙や壁など）」に当て、ボタンを **1回** 押してください。
「おぼえたよ！」と表示されたら準備完了です。
※起動時にボタンを押さずにいると、この設定をスキップして前回設定値で開始できます。

---

## 基本の操作方法
ATOM S3本体の画面（ディスプレイ自体がボタンになっています）を押して操作します。

- **1回押す (シングルクリック)**: 目の前の色を「採取」します。
- **2回連続で押す (ダブルクリック)**: 「いろさがしゲーム」と「ライトモード」を切り替えます。
- **長押し**: 現在採取している色をすべてリセット（やり直し）します。

---

## 2つのモードの遊び方

### 🟢 モード 1: いろさがしゲーム (Hunt Game)
ランダムに出題された「もくひょうの色」を現実世界から探し出し、色を混ぜて作るゲームです。
1. 画面の四角い色が目標の色です。
2. 色を探してボタンを1回押し、色を採取します（最大2色）。
3. 2色採取すると「クリックで判定！」と表示されるので、もう一度押すと判定されます。
4. **ヒント機能（カラーバー）**: 画面中段のカラーバーには、「目標の色（▽）」と「採取した色（△）」が表示されます。これを見て、足りない色を直感的に探すことができます。
5. **絵の具の混色**: 2色採取した場合、光の混色（RGB）ではなく、**絵の具の混色（RYB）**のロジックで色が混ざります。（例：黄色＋青＝緑）

### 🟡 モード 2: ライトモード (Light Mode)
採取した色でステッキの先端（LEDテープ）を魔法のトーチのように光らせるモードです（最大3色まで）。
1. **1色だけ**採取したとき: その色でLEDがずっと光ります。
2. **2色〜3色**採取したとき: 採取した色同士が、ゆっくりと滑らかに入れ替わるアニメーション（クロスフェード）で光ります。
3. **🌈【隠し機能】にじいろモード**: 
   3つの色を採取したとき、その3色が「色彩学的にバランスの良い組み合わせ（トライアド配色＝色相環で約120度ずつ離れた色）」だった場合、隠しコマンドが発動してステッキが虹色に輝きます！

---

## システム構成
- **ハードウェア**: M5Stack ATOM S3, TCS34725 (カラーセンサー), WS2813 (LEDテープ), TailBat, パッシブブザー
- **ソフトウェア**: PlatformIO (C++) / `M5Unified`, `FastLED`
- **混色アルゴリズム**: RGBからRYB空間への変換と、極座標系でのベクトル合成によるシミュレーション。
