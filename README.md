# Color Collector (ATOM S3)
魔法のステッキのように、現実世界から「色」を採取して遊べる体験型ガジェットです。

## はじめに（ホワイトバランス設定）
起動すると、画面に「しろいろを おぼえさせるよ」と表示されます。
使用する環境（暗闇など）で、付属の白色LEDを「白い物体（紙や壁など）」に当て、反射光をセンサーに向けた状態で**ボタンを1回**押してください。
「おぼえたよ！」と表示されたら準備完了です。
※長押しするとこの設定をスキップすることもできます。

---

## 基本の操作方法
ATOM S3本体の画面（ディスプレイ自体がボタンになっています）を押して操作します。

- **1回押す (シングルクリック)**: 目の前の色を「採取」します。（採取しただけではまだ判定されません）
- **長押し (1秒以上)**: 「いろさがしゲーム」では、採取した色で正解判定をします。「ライトモード」では採取した色をリセットします。
- **2回連続で押す (ダブルクリック)**: 「いろさがしゲーム」と「ライトモード」を切り替えます。

---

## 2つのモードの遊び方

### 🟢 モード 1: いろさがしゲーム (Hunt Game)
ランダムに決まった「もくひょうの色」を探し出すゲームです。
1. 画面に表示される四角い色が、今回の目標の色です。
2. その色に近いものを探し、センサーを当ててボタンを1回押します（最大2色まで採取可能）。
3. 2色採取すると画面に「クリックで判定！」と表示されます。そこでもう1度クリックすると正解判定が行われます。
4. 正解すると「せいかい！！」と表示されピンポン音が鳴ります。大きくズレていると「ざんねん…」と表示されブッブー音が鳴ります。ズレの角度（度）も表示されます。
5. **ヒント**: 2色採取した場合は、その2色が混ざった色（絵の具のように足し合わされた色）で判定されます。1色では作れない色は、2色を混ぜて正解を目指しましょう！

### 🟡 モード 2: ライトモード (Light Mode)
採取した色でLEDテープを光らせるモードです（最大3色まで）。
1. **1色だけ**採取したとき: その色でLEDがずっと光ります。
2. **2色〜3色**採取したとき: 採取した色同士が、ゆっくりと滑らかに入れ替わるアニメーション（クロスフェード）で光ります。
3. **🌈【隠し機能】にじいろモード**: 
   3つの色を採取したとき、その3色が「とてもバランスの良い組み合わせ（色相環で約120度ずつ離れた色）」だった場合、隠しコマンドが発動してLEDが虹色に輝きます！
